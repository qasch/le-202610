# Übungen zu `locate`

## Vorbereitung

Stelle sicher, dass `locate` installiert ist. Auf aktuellen Debian-Systemen wird dafür in der Regel das Paket `plocate` verwendet. Das Kommando selbst heißt anschließend weiterhin `locate`.

Wechsel in den Account von `root` mit `su -` und führe folgende Kommandos aus:

```bash
apt update
apt install plocate
```

Wechsel nach der Installation wieder in den Account deines regulären Users mit:

```bash
exit
```

> [!NOTE]
> Falls du bereits `sudo` installiert und eingerichtet hast, kannst du natürlich auch `sudo` nutzen, falls erforderlich.

## Übung 3: Geschwindigkeitsvergleich `locate` vs. `find`

> [!NOTE]
> Mit dem Kommando `time` kann man messen, wie lange ein Kommando für seine Ausführung benötigt. Dazu stellen wir `time` einfach vor das auszuführende Kommando.
>
> Wir wollen nun `locate` mit `find`, einem anderen Kommando zur Suche nach Dateien, vergleichen. Die eigentlichen Suchergebnisse interessieren uns hier nicht, daher leiten wir sie nach `/dev/null` um.

1. Miss die Zeit, die `locate` für die Suche benötigt:

   ```bash
   time locate bash > /dev/null
   ```

2. Miss anschließend die Zeit für eine Suche mit `find`, die ausgehend von `/` das Dateisystem durchsucht:

   ```bash
   time find / -name "*bash*" &>/dev/null
   ```

3. Vergleiche die gemessenen Zeiten.

4. Beantworte anschließend folgende Fragen:

   - Warum ist `locate` normalerweise deutlich schneller?
   - Durchsuchen `locate` und `find` bei diesen beiden Kommandos tatsächlich auf dieselbe Weise dieselben Daten?
   - Ist der Geschwindigkeitsvergleich daher wirklich fair?
   - Welche Nachteile muss man für den Geschwindigkeitsvorteil von `locate` in Kauf nehmen?

> [!NOTE]
> Wir schauen uns `find` und seine Syntax später noch genauer an. Du kannst dich aber natürlich schon einmal in der Manpage informieren.
